# ResolveIT API

**Plataforma de Gestão de Serviços de TI e Chamados Técnicos**

## Sobre o projeto

O ResolveIT é uma API REST desenvolvida para gerenciar chamados de suporte técnico em organizações. O sistema tem como objetivo organizar o atendimento, controlar prioridades, acompanhar a resolução de incidentes e manter o histórico das operações.

O projeto está sendo desenvolvido como parte de um portfólio de Backend Python, com foco em boas práticas de desenvolvimento, segurança, testes automatizados e organização da arquitetura.

## Funcionalidades planejadas

* [ ] Cadastro e autenticação de usuários
* [ ] Controle de acesso por perfil
* [ ] Gestão de organizações
* [ ] Abertura, consulta e atualização de chamados
* [ ] Atribuição de chamados a técnicos
* [ ] Comentários e histórico de alterações
* [ ] Controle de prazos de atendimento (SLA)
* [ ] Indicadores operacionais
* [ ] Testes automatizados
* [ ] Execução com Docker

## Tecnologias planejadas

* Python
* FastAPI
* Pydantic
* PostgreSQL
* SQLAlchemy
* Alembic
* Pytest
* HTTPX
* Docker e Docker Compose
* Git e GitHub Actions

Construir uma API de gestão de chamados com arquitetura organizada, regras de negócio bem definidas, segurança e documentação adequada para demonstrar conhecimentos de desenvolvimento Backend Python.
